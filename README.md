# 🚀 Next.js App Starter

A modern **Next.js** application bootstrapped with  
[`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

This project is built using the **App Router**, optimized fonts, and a clean project structure—ready for development and deployment.

---

## ✨ Features

- ⚡ **Next.js App Router**
- 🎨 Optimized font loading with **next/font (Geist)**
- 🔥 Fast Refresh & Hot Reload
- 📁 Clean and scalable folder structure
- 🌐 Ready for deployment on **Vercel**
